# Northline Inventory

Northline Inventory is a system that is utilized by warehouse teams for the purpose of the tracking of stock levels across multiple locations in order to facilitate better visibility.

## Getting started

In order to ensure that the application is able to be utilized successfully, users should first make sure that they have been provided with access credentials by an administrator prior to any attempt being made to log in. Once login has been accomplished, it is recommended that the configuration of the default warehouse location be performed so that subsequent operations will be associated with the correct site. A number of environment variables may need to be set depending on the particular deployment scenario that is being undertaken, after which a restart of the service should be carried out. Documentation regarding advanced topics can be found elsewhere and should be consulted in the event that issues are encountered.
